# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues.

The repository remote is `https://github.com/Chandra179/nadir.git`. Use the
GitHub issue integration or `gh` when available. PRDs are created as issues
with the `needs-triage` label.

## Conventions

- Create a PRD as one GitHub issue with a descriptive title and the complete
  PRD body.
- Keep implementation detail at the module and interface level; avoid making
  file paths part of the issue contract.
- Apply `needs-triage` when publishing a new PRD.
