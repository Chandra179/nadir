# Triage Labels

| Role | Label | Meaning |
|---|---|---|
| Needs evaluation | `needs-triage` | Maintainer needs to evaluate the issue |
| Needs reporter input | `needs-info` | Waiting on more information |
| Ready for agent | `ready-for-agent` | Fully specified and ready for implementation |
| Ready for human | `ready-for-human` | Requires human implementation or judgment |
| Won't fix | `wontfix` | Will not be actioned |
